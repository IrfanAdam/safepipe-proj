Spec — a11y + contract

Do: keep query and pills in one row, announce results politely, wrap only after wide pill sets would clip. Don't: split the pair across rows, or ship the placeholder as the only label.

Spec · a11y + related

A11y — input[type="search"] in role="search", icon aria-hidden, pills are aria-pressed toggles in a labelled group, results via aria-live="polite". Related — field owns value capture · progress owns result-count loading · status owns error flags.
