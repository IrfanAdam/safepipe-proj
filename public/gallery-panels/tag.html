Spec — states

Tags are static ink — only toggles take hover, selection and focus. Selected swaps to the semantic or provider fill; disabled drops to page fill with muted text. Loading and error do not exist at tag level.

Spec — a11y + do / don't

Static tags get no role — plain text in context. Toggle tags are buttons with aria-pressed and a var(--sp-spacing-sm) minimum hit height. White on danger clears at var(--sp-text-xs); warning always takes dark ink, never white.

  • 01

    Do: give every color exactly one meaning — danger never appears on a passing row.

  • 02

    Do: let the uppercase label carry status meaning so it reads without color.

  • 03

    Don't: shrink below var(--sp-text-xs) to fit — shorten the word instead; don't hand-pick near-gray ink.
