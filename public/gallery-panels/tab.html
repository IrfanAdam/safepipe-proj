Spec — states

Hover darkens one step and steps the label up; selected holds full weight with its second cue; focus always rings; disabled mutes and drops the pointer. Tabs swap instantly, so loading and error live in the panel below, never on the tab.

Spec — a11y + do / don't

Wrapper role="tablist", each tab role="tab" with aria-selected; arrows move focus with roving tabindex. Inactive labels must clear 4.5:1, and the ring must read on both card and page surfaces.

  • 01

    Do: keep one tab set per view — tabs swap content in place, they never navigate to a different page.

  • 02

    Do: pair the label step with lift or dot so selection survives without color.

  • 03

    Don't: stack past two pill rows, or invent a label size between nav and pill text.
