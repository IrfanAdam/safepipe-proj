Spec — states

Hover fills var(--sp-surface-input) with var(--sp-text-primary) ink; active is the tab.md selected state; focus rings var(--sp-sky) inside the item. Disabled drops to var(--sp-text-muted) with no hover fill — hidden destinations are removed, not disabled. Loading and errors report in content, never in the rail.

Spec — a11y + contract

Do: one active section, icon-only items with names plus tooltips, keyboard order logo → avatar → primary → utility. Don't: fork a second nav-item style, nest a second highlight, or park actions in the rail.

Spec · a11y + related

A11y — nav[aria-label="Primary"] with list markup, current page aria-current="page", hit target ≥ var(--sp-spacing-3xl) square. Related — header owns page actions · tab owns the item state · progress owns section-load feedback.
