Components · Data · List Row

One action per row. The row is the link.

List Row is one record stretched across the page width — leading icon, title, meta line, trailing action — the repeating unit inside every list. Use it when records must scan and compare; reach for card when one record needs depth, footers, or multiple actions.

  • 01

    The row is a single link. Title, meta at text.xs, tag.md qualifiers, and one trailing text.md icon compose one target with padding spacing.lg / spacing.md. Multi-action records belong in card.md; per-row menus live in the trailing slot only.

    Reject: three competing links inside one row — stacked targets misfire on touch.

  • 02

    Selected is border weight plus sky, never a flood. Measured selection is stroke weight with the meta count switching to color.brand.sky — implement as color.border.strong plus the sky accent with aria-current="true". The page tone stays color.surface.page behind the stack.

    Reject: a full-bleed tint wash for selection — floods flatten the stack rhythm.

  • 03

    Meta stays small; hierarchy outgrows the row. Meta at text.xs dense / text.sm record, rows stacked with spacing.md gaps owned by the list. If a record needs heading hierarchy it has outgrown the row and becomes a card.

    Reject: a bold 18px headline inside a 44px dense line — the row bursts its metrics.
