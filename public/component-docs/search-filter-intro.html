Components · Form · Search / Filter

Query narrows the text, pills narrow the facets — one row.

Search / Filter is the query-plus-narrowing pair that sits above every list: one free-text input, one row of toggleable filter pills. Use it when the user narrows a list; reach for field when capturing a single value to keep.

  • 01

    Search and filters are one pattern. The color.surface.card shell at radius.lg with spacing.xl / spacing.md padding and the pill row at spacing.sm gaps ship together and reflow together — loading swaps the results count for progress.md, never the row width.

    Reject: the query in the toolbar and the pills three sections down — split rows desync.

  • 02

    Selected is dot plus border, never color alone. The active pill keeps its color.surface.card fill and adds the 8px color.brand.sky dot with a color.border.strong border — and stays a real toggle with aria-pressed inside a labelled group.

    Reject: a tint change as the only selected signal — color alone fails color-blind users.

  • 03

    The placeholder is a hint, never the label. Placeholder sits at text.sm in color.text.muted; the field still needs an accessible name, the icon stays aria-hidden, and results announce through aria-live="polite".

    Reject: the measured pale placeholder as the only label — it fails contrast and vanishes on type.
