Components · Actions · Button

One primary per region. Never a second.

Button is the only component that commits a change — forms, dialogs, toolbars. Use it when the user commits, advances, or confirms; reach for a ghost when the action is additive, an icon button when the toolbar is tight, a link when nothing is committed.

  • 01

    Frame — holds through loading. The spinner swaps in at var(--sp-text-md) metric while the button keeps its measured width and announces aria-busy; the layout never jumps when work starts.

    Reject: a button that collapses to a bare spinner and shoves the whole row sideways.

  • 02

    Emphasis — navy commits, danger destroys. Primary is the single var(--sp-navy) commit per region; var(--sp-danger) fills only irreversible actions confirmed inline; neutral and ghost step down from there.

    Reject: a red Save because it felt urgent, or two navy primaries sharing one footer.

  • 03

    Target — ringed and reachable. The var(--sp-sky) focus ring sits at var(--sp-radius-lg) offset, every target clears 44px, and icon-only squares keep an accessible name with them.

    Reject: a 24px icon-only hit with its ring clipped by dialog overflow.
