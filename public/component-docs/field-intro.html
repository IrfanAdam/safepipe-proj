Components · Form · Field

Labels stay visible. Placeholders never replace them.

Field captures one value with a persistent label above the box, so validation and read-only states stay unambiguous. Use it when a form needs one named value; reach for search-filter when the input narrows a list, the date or textarea form when the kind is fixed.

  • 01

    Label — above, always. The visible label is the accessible name, wired with for; the placeholder hints in var(--sp-text-muted) at var(--sp-text-md) while the value speaks in var(--sp-text-primary).

    Reject: a placeholder-only field whose question vanishes the moment you type.

  • 02

    Error — arrives as a pair. var(--sp-danger) border plus the message below it, wired with aria-describedby and aria-invalid; the label never moves and color never speaks alone.

    Reject: a red border with no message — a screen reader hears nothing change.

  • 03

    Shape — two heights, one radius. Small and Medium share var(--sp-radius-md) with var(--sp-border-default) chrome; the legacy pill-shaped password field is off-system and must not be copied.

    Reject: a third height borrowed from the search field, or a fully rounded input.
