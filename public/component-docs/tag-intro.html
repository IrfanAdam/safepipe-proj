Components · Data · Tag

Tags label. They never act.

Tag is the compact, non-interactive chip that classifies an object — provider, work type, compliance state — so lists stay scannable. Use it when a word describes; reach for the toggle form only when it switches state, a tab when it navigates, a filter when it narrows a list.

  • 01

    Meaning — one color, one meaning. var(--sp-danger) never appears on a tag that is not a compliance failure; var(--sp-warning) collapses overflow, var(--sp-violet) carries provider identity, var(--sp-success) confirms.

    Reject: a violet tag on a failed row because it matches the brand — color is a contract, not decoration.

  • 02

    Behavior — labels, not buttons. Static tags carry no role and take no click; only the toggle form renders a button with aria-pressed. If it filters or navigates it belongs to search-filter or tab.

    Reject: a clickable chip-shaped div with no name, no role, and no keyboard path.

  • 03

    Ink — follows the fill. var(--sp-text-inverse) on fills darker than var(--sp-border-strong), var(--sp-text-primary) on light fills; the label stays var(--sp-text-xs) bold — shorten the word, never shrink below it.

    Reject: hand-picked gray on violet, or tiny type squeezed so the tag fits the column.
