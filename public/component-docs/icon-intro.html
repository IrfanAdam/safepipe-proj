Components · Foundations · Icon

Icons speak before labels load.

Icon is the inline SVG glyph set behind rails, rows and dialogs — 31 masters lifted from the live library, instance-resolved and translated to origin. Use it when a control needs a glanceable mark; reach for text alone when the meaning cannot survive without words.

  • 01

    Geometry — one master, one glyph. Every icon resolves its Icon= master to vector paths with a normalized viewBox, sized by the size attribute onto var(--sp-text-xs) through var(--sp-text-2xl) — 12, 16, 20, 28 and nothing else.

    Reject: a hand-traced glyph at an off-grid box, or a pixel-sized rule that bypasses the size scale.

  • 02

    Ink — currentColor, always. Glyphs carry no baked fill; they inherit the surrounding text token (var(--sp-text-primary), var(--sp-danger), var(--sp-sky)), so tone changes with context instead of forking new assets.

    Reject: a hex-baked glyph that cannot follow a danger row or an inverse surface.

  • 03

    Meaning — never color or glyph alone. Decorative icons stay aria-hidden; a meaningful icon repeats its label in adjacent text or names its control — the glyph accelerates, it never carries meaning solo.

    Reject: an icon-only button with no accessible name, or a status told by color with no word beside it.
