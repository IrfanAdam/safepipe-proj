Components · Data · Status

Every dot ships with its label. Color never speaks alone.

Status is the at-a-glance state indicator — a dot plus label for rows, and a composite card grouping compliance counts with their tags. Use it when a row needs a state; reach for a tag when the word only classifies, progress when the state is still computing.

  • 01

    Pairing — dot plus words, always. The dot is aria-hidden decoration; the visible label carries the meaning and goes live through role="status" when the state changes at runtime.

    Reject: a lone red dot with the state locked inside a tooltip nobody opens.

  • 02

    Card — one form per list. The horizontal strip is the default with var(--sp-radius-md) row padding; vertical lives on narrow rails only. The card is a row, not a dialog — it never takes dialog radius.

    Reject: a vertical card stretched across a full-width list, or dialog chrome on a strip.

  • 03

    Tone — maps one-to-one. Each measured hue maps to its key: var(--sp-success) compliant, var(--sp-danger) non-compliant, var(--sp-warning) due, var(--sp-violet) upload, var(--sp-navy) incomplete. Never recolor a state to fit a palette.

    Reject: a teal failed because the dashboard theme is teal.
