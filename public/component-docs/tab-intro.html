Components · Navigation · Tab

Tabs swap views in place. They never navigate away.

Tab is the single-select control that switches views of the same dataset without leaving the page — page headers, filter bars, step panels. Use it when content swaps in place; reach for a link when the destination is a different page, a tag when the word only classifies.

  • 01

    Selection — reads without color alone. The selected tab steps its label to full-strength var(--sp-text-primary) and pairs it with a second cue: var(--sp-elevation-1) lift on floating tabs, the var(--sp-sky) data dot on pills.

    Reject: a selected tab that differs only in hue — without the lift or the dot, the state vanishes for colorblind users.

  • 02

    Scale — one set per view, two rows max. Pills wrap onto the multi-row pattern; past two rows the IA needs rethinking. Nav tabs set var(--sp-text-md), filter pills var(--sp-text-sm) — never a size between the two.

    Reject: three stacked pill rows, or a halfway label size invented to squeeze one more tab in.

  • 03

    Focus — roving keys, full-size target. The wrapper owns role="tablist", each tab role="tab" with aria-selected and arrow-key roving tabindex; the var(--sp-sky) ring is never removed and the hit area pads out to var(--sp-spacing-2xl).

    Reject: every tab in the tab order with no visible ring — a keyboard user must always see where they are.
